# HackPad-Macropad
This is a customized macro pad by me.
It is designed for coding shortcuts and as a music controller. 
The Encode/Knob represents a volume knob

# Process
I started the macro pad around 5 days ago. I started with the guide; first, I was following every single guide then after seeing other's macropad's i also thought i will also add some more components so it will look good and a bit better for me. Then I started with the schematic; it was a bit hard, but everything went well. Then came the PCB. The hardest part was the routing(that was the second time doing a PCB all by myself). I got so frustrated, so I installed this app on my laptop called Freerouting, which did the hard work for me in seconds. I felt relief. Then the 3rd hardest challenge came for me: designing the case in Fusion 360. I sat for 5-6 hrs(I did not record it cause i did not know that we could record)and was halfway done. Today[10/22/2026], I finished the CAD project and my firmware. I was so excited for the outcome. This evening I made my rep in my github which is this. It also took me some time. That's all!!!
