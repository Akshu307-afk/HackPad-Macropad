# CodePad :joystick:
This is a customized macro pad by me.
It is designed for coding shortcuts and as a music controller. 

# Features :sparkles:
 * This has a 3x4 MacroPad that uses a rotary encoder and an OLED Display and uses [QMK](https://qmk.fm/) firmware.
 * 128x32 OLED Display
 * EC11 Rotary encoder for its thing to do (LOL)
* 12 Keys

# Firmware overview
This hackpad uses QMK firmware for everything.

 - The rotary encoder changes volume. Press to mute
 - The 4 keys currently act as macros.
 - The OLED displays the current song that you are playing

# Proccess :fire:
I started the macro pad around 5 days ago. Then the 3rd hardest challenge came for me: designing the case in Fusion 360. I sat for 5-6 hrs(I did not record it cause i did not know that we could record)and was halfway done. Today[10/22/2026], I finished the CAD project and my firmware. I was so excited for the outcome. This evening I made my rep in my github which is this. It also took me some time. That's all!!!
